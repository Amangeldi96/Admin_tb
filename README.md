# Токтогул Базар — React админ-панели

Компьютерге жана телефонго ылайыкташкан React + Vite админ-панель. Firebase Authentication жана Firestore менен иштейт.

## Иштетүү

1. Node.js 20+ орнотуңуз.
2. `.env` файлындагы Firebase маалыматтарын текшериңиз.
3. Терминалда:

```bash
npm install
npm run dev
```

Даяр версияны чыгаруу: `npm run build`. Натыйжа `dist` папкасында болот.

## Мүмкүнчүлүктөр

- Email/сырсөз аркылуу админ болуп кирүү
- Жалпы статистика жана акыркы аракеттер
- Кадимки жана VIP жарнамаларды кабыл алуу же өчүрүү
- Колдонуучуларды 1, 3, 7 же 30 күнгө блоктоо жана кайра ачуу
- Эреже бузуулар жана администратор аракеттеринин журналы
- Компьютер жана телефон үчүн адаптивдүү дизайн
- `hobbyplus312@gmail.com` админ аккаунту менен корголгон кирүү экраны
- Үстүңкү жалпы издөө жана мобилдик bottom-navigation
- Firebase каталарын интерфейсте түшүнүктүү көрсөтүү
- Даяр `dist` папкасы Vercel'ге түз жүктөөгө ылайык

## Коопсуздук

Панель `hobbyplus312@gmail.com` дарегин интерфейсте админ катары тааныйт. Өндүрүштө бул аккаунтка ишенимдүү серверден Firebase Custom Claim `admin: true` бериңиз. Учурдагы Firestore эрежелерин колдонмонун коллекцияларына жараша өзүнчө текшерип, админдин жазуу аракеттерин `request.auth.token.admin == true` шарты менен коргоңуз. Даяр эмес жалпы эрежени түз эле жарыялоо колдонуучулардын колдонмосун токтотушу мүмкүн. Service Account сырын браузерге же `.env` файлына салбаңыз.

Firebase Console → Authentication → Users бөлүмүндө `hobbyplus312@gmail.com` аккаунту алдын ала түзүлгөн жана сырсөзү коюлган болушу керек.
